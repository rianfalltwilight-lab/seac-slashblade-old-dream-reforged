## Summary

Restores classic SlashBlade combat and mechanics in SlashBlade: Resharped, with dual wielding and per-player combat mode switching.

## Requirements

- Minecraft **1.21.1**, **NeoForge**, and **Java 21**.
- Install this addon on **both the client and server** for multiplayer.
- Required parent mod: **SlashBlade: Resharped** ([CurseForge](https://www.curseforge.com/minecraft/mc-mods/slashblade-resharped), [Modrinth](https://modrinth.com/mod/slashblade-resharped)).
- Declare the parent mod as a required project dependency in uploaded versions. The build's pinned parent version is for reproducibility; it is not the only version allowed by the runtime metadata.
- The license field describes the combined terms linked above. Keep the standalone MIT and original upstream documents available.
