# 0.2.0-dev.3

[直接下载运行 JAR](https://github.com/rianfalltwilight-lab/seac-slashblade-old-dream-reforged/releases/download/v0.2.0-dev.3/SEAC-SlashBlade-Old-Dream-Reforged-1.21.1-0.2.0-dev.3.jar)

同步 dev.2 与 dev.3，继续以 Minecraft 1.7.10 r87（83429584fc2ee437cb48c2d31d23f353cb72bd84）为行为基准。

- 修复摔落保护持续右键缓降和挥刀停止下降、火焰保护使用与灭火、剑类常规附魔适用性，以及命名敌怪/Boss 击杀奖励；保留现代保护和取消事件。
- 增加可自定义 Lock-on 按键，默认左 Shift，复用原战斗输入。
- 修复特殊行动键（默认 V）的超 SA：持续按住至少 20 个服务端 tick 后松键释放，持续按住不会自动发动；九种基础 SA 有 r87 默认超次元斩回退，附属独立 Super 保留。
- 恢复蓄力粒子、源刀半耐久结算及次元斩冻结行为，处理切换物品与重复释放边界。

冻结交付验证：31 项 Super 输入断言全部通过；含 NegoreRouse、SI 附属的 102 项核心计数断言及附加检查通过。真实 V 按键网络流程对散华、aeon_blade、fox_faerie 均通过，10 张原图完成审阅，正常存档退出。最终清理构建的 JAR 与 GUI 候选相同。dev.2 缓降与独立 Lock-on 另有真实客户端回归。

MC 1.21.1 / NeoForge 21.1.248 / Java 21，实际依赖重锋 2.0.5。客户端与服务端同步升级。两项附属不在本 Release 内；不是完整整包或多人压力验收，原场景已有配方报错不称零错误。测试探针不进入运行 JAR。
