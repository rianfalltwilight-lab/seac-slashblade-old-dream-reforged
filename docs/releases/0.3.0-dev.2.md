# 0.3.0-dev.2：女仆拔刀时间轴性能修复

修复持刀女仆空闲时间增长后，拔刀时间轴反复扫描空区间带来的实体 tick 开销。改为只查询已登记的动作，保留回调顺序、进度和异常语义；不修改女仆攻击策略、伤害、刀的成长数据或玩家模式。

- 对已知上游实现进行字节码指纹检查；若上游或其他转换已改变逻辑，跳过优化并记录日志。
- 不新增女仆硬依赖，NeoForge 与拔刀声明范围保持不变。
- 继承 0.3.0-dev.1 的每位玩家独立切换怀旧／重锋功能。

验证：846 项服务端断言通过；真实女仆攻击入口的连段、逐 tick 累计伤害、杀敌数、耀魂、精炼及耐久与基线一致。冻结源码独立重建 JAR 字节一致。

受控单实体测试中，距上次动作 2000 万 tick 时，平均耗时由 52.747 ms 降至 0.089 ms。该测试关闭寻路 AI，不代表生产整服 MSPT 或固定性能提升比例。

实际验证 Minecraft 1.21.1 / NeoForge 21.1.248 / SlashBlade 2.0.5 / Java 21。未完成完整生产整包、真实玩家画面、大规模女仆群、老世界实体卸载重载和长期性能验收。

开发预发布。只安装主 JAR；测试探针与第三方依赖不随发行包提供。公开包仅调整名称与法律说明，程序和游戏资源与冻结候选一致，哈希见 release-manifest.json 和 SHA256SUMS.txt。
