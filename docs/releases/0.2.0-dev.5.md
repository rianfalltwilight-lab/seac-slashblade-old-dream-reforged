# 0.2.0-dev.5

[直接下载运行 JAR](https://github.com/rianfalltwilight-lab/seac-slashblade-old-dream-reforged/releases/download/v0.2.0-dev.5/SEAC-SlashBlade-Old-Dream-Reforged-1.21.1-0.2.0-dev.5.jar)

同步 dev.4 空中回避与 dev.5 稳定性、加载器范围及封面更新。仍为单一 1.7.10 r87 规则，包含之前的超 SA 松键释放修复。

- 特殊行动键（默认 V）恢复地面/空中方向回避，保留竖直运动；服务端验证间隔与三连上限，修复上闪后立即冲刺被拉回。客户端与服务端必须同步更新。
- NeoForge 必需依赖声明放宽至 `[21.1,)`，Minecraft 仍锁定 1.21.1，Java 21。默认构建保持 21.1.248，支持隔离验证参数 `-PneoForgeVersion=21.1.233`。
- 重锋仍为必需前置，实际验证 2.0.5；该前置自身要求 NeoForge `[21.1.228,)`，安装组合以所有前置要求的交集为准。实测 21.1.233、21.1.248，不代表所有补丁均兼容。
- 新增用户提供并经 AI 编辑的宣传封面，在模组详情页显示；游戏内材质与模型不受封面变更影响。

验证：21.1.233 与 21.1.248 的 102 项核心计数断言及附属回归通过；233 上 31 项超 SA、35 项回避断言通过。最终 248 最小客户端的四把刀连段、伤害、下劈、Barrier、模型及封面检查通过，9 张截图完成审阅，正常存档退出。独立源码构建哈希相同；dev.5 的运行类与 dev.4 相同。

这是限定的开发验证，不是正式整包、多人高延迟、全部 Boss 或长期负载验收。两项附属不内置于本仓库发行包。现有 21.1.248 可继续使用，不要求更换加载器。

公开 JAR 使用冻结候选的程序和资源，仅调整公开身份与法律来源说明。原始与公开附件哈希、逐条目对照见 release-manifest.json。源码包完整可重建；测试探针不得放入玩家 mods。开发预发布，未部署生产。
