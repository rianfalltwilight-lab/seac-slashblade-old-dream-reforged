# SEAC拔刀剑附属 旧梦重铸 0.1.0-dev.11

开发预发布；Minecraft 1.21.1 / NeoForge 21.1.248 / Java 21 / SlashBlade: Resharpened 2.0.5-1.21.1。客户端与服务端须使用同版本。

## 更新

- 连续右键：恢复完整动作片段，人物动作与刀身挂点同步为 6 tick；保留 SAYA1 → SAYA2 → BATTOU 连段和输入窗口，横斩使用配套横斩动作。
- 剑气方向：移除多余的 90° 旋转，近战斩击与飞行剑气统一方向。
- 下劈落地：起手立即下落，接地进入独立 HELM_LANDING，重置时钟并于 6 tick 后收刀；落地不重复攻击或触发 SE。
- 剑气存档：EntityDrive 空击退值恢复为原生 KnockBacks.cancel，避免 NBT 保存异常；保留非空击退效果。

神钢抢夺 III 和其他刀属性保持不变。使用重锋已有配套模型/动画资源，不宣称完整逐帧复刻旧版。

## 验证

公开源码由 Java CI 和标签流程重新构建、运行最小服务端契约并核对固定 SHA-256。新增契约覆盖下落、落地时钟、原生 FallHandler、剑气 roll 与空击退实体保存/读取。

权威研发记录另有实际 GUI 客户端专项验证：散华和神威刀连续右键得到三段连招，第一/第三人称截图核对方向与挂点；从地板上方 8 格的下劈在 6 tick 内实际接地。输入通过游戏 API 发包，下劈起手由脚本触发，未验证硬件按键组合。该证据来自内部开发候选，公开包保留相同 Java 实现但更改公开名称和许可证封装，公开包不另声称 GUI 重测。

未重跑完整 247 模组整包、专服多人/高延迟、所有刀型/SA/SE 或长期战斗；Botania/SI 在公开最小环境缺失时明确跳过。没有 FPS/MSPT 性能提升承诺。

## 安装与回退

五项资产：运行 JAR、sources JAR、源码 ZIP、manifest、SHA-256 清单。仅运行 JAR 放入 mods。测试 client-probe 不发布到 Release；源码中保留探针及独立构建任务以便复验。第三方依赖单独安装。

新增落地组合状态；回退前须在世界备份副本验证刀状态恢复。此发布不部署生产服务器或玩家整包。独立代码 MIT，旧版衍生内容继续保留原作者条款及 AI 披露。
