# SEAC拔刀剑附属 旧梦重铸 0.2.0-dev.1

开发预发布，行为基准更新为 SlashBlade mc1.7.10-r87。MC 1.21.1 / NeoForge 21.1.248 / Java 21。重锋仍是必需依赖；版本范围放宽为 [0,)，实际构建与验收锁定 2.0.5-1.21.1，其他内部 API 版本未逐一验证。

## 更新

- r87 地面、空中、冲刺连段与程序化刀身动作；保留第一人称转视角补偿、下劈落地、退出重进配置保护。

- 旧附魔池、耀魂附魔、铁砧修刀/锻造、断刀边界、燃烧刀架、六种原生具名刀魂及收刀修复。

## 验证与配套关系

本 Release 只包含旧梦重铸自身源码及运行包。内部冻结三件套还包含 NR 1.3.2-scex.5-dev、SI 拔刀集成 0.1.0-dev.5；这些是外部候选，不随本仓库发布。NR 黑洞/追踪飞刀筛选修复属于 NR 配套候选，不能通过单独更新本 JAR 获得。

内部三件套记录：26 把附属刀、13 SA/15 SE 入口；251 JAR 模组清单在新配置/新世界通过；真 GUI 盖亚伤害路径 19 场景、动作图像复核，以及真实重进/维度往返 26 刀组件不变。盖亚由夹具冻结 AI，非完整仪式。公开 CI 仅重跑主模组的 r87 最小契约，缺失外部附属时明确跳过；内部 GUI/整合证据不等于公开重命名 JAR 或单模组重新完成全部组合测试。

固定模拟负载 5400 tick 样本无 >50 ms，8 攻击者/32 目标候选 p95 为 3.91–4.42 ms。基线仍安装附属，仅改变 full-r87 开关；不是原生重锋基线，也不代表真玩家网络或长期性能。

未验收原配置完整客户端包、独立专服真玩家多人/高延迟、完整盖亚仪式、全部第三方刀型/光影、生产旧世界升级与长期性能。
