# 0.3.0-dev.3：Just Guard 修复与怀旧交互补充

- 修复 Just Guard 恢复药水效果时可能出现的 ConcurrentModificationException；保留逐项事件回调与取消语义。
- 怀旧模式支持对刀架左键喂普通耀魂材料，潜行时优先喂养，每次消耗一个；不直接精炼或修复。碎耀魂、耀魂、耀魂铁锭、耀魂宝珠、耀魂结晶和耀魂宝玉分别增加 100、200、400、400、500、500 刀魂。附魔、SA、SE 及命名刀材料不适用。此项是用户扩展，不是 r87 原样行为。
- Super SA 默认尊重 Unbreakable；可通过配置恢复 r87 的半耐久消耗规则。
- 新增 attackFriendlyEntities 配置，默认关闭；开启后仍遵守宠物、队友、乘骑与 PvP 保护。关闭时仍可反击已经主动攻击玩家的生物。重锋模式规则保持原样。
- 新配置默认值：enableDirectSoulFeeding=true、superArtsRespectUnbreakable=true、attackFriendlyEntities=false。

继承 dev.2 的女仆时间轴优化与每位玩家独立切换怀旧／重锋功能。Minecraft 1.21.1 / Java 21；加载器和前置声明范围保持原样，不把本轮测试版本写成最低要求。
