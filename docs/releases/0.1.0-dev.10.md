## 验证边界

公开源码构建与隔离契约由 Java CI 和标签发布流程重新运行。运行 JAR 不含测试类、外部依赖或生产数据。

权威研发 dev.10 另有最小环境及锁定整包 success=true 记录：67 项具名刀中 65 项三连段通过，2 项未返回 BladeState 明确跳过；覆盖 SI 的 10 把电力刀基础耗电和序列化。完整依赖和内部日志不随公开仓库分发；公开 CI 只运行最小环境，SI 缺失时标记跳过。该结果不表示所有附属特效均已验收。

尚未完成真实第一/第三人称观感、多人高延迟、真实网络包、旧世界卸载及规模性能验收。减少分配的代码变更没有实测性能提升承诺。发布不包含服务器或玩家整包部署。
