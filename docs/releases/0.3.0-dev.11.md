# SlashBlade Reborn 0.3.0-dev.11

Minecraft 1.21.1 · NeoForge · Java 21 · Client and server

- Updated compatibility with SlashBlade: Resharped 2.2.1. Strict legacy mode can again set a blade to half durability after a super art.
- F8 mode switching now handles owned summoned swords that stop ticking outside simulation range, during a tick freeze, or in another dimension. Stalled addon swords keep their own lifecycle.
- Super arts now charge durability on the damage tick. AirTrick skips inactive teleport anchors, owner-bound special attacks no longer replay after a chunk reload, and Spiral/Blistering clears stale held-volley state.
