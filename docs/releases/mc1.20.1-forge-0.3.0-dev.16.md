# 拔刀剑：旧梦重铸 — 1.20.1 Forge dev.16

版本：`0.3.0-dev.16`，适用于 Minecraft 1.20.1 / Forge / Java 17。

这次主要改善锁定、追击和幻影剑的手感，并减少战斗时的重复计算。

- **幻影剑扎中敌人后，可以直接穿墙追击。** 已命中的幻影剑会留下追击位置，AirTrick 可以直接移到目标身边，这次直达不额外消耗耀魂。
- **旧模式下，锁定更好用。** 准星直接指向动物等被动生物时也能锁定；宠物、队友和服务器的伤害保护照常生效。
- **按住锁定后，不容易断档。** 目标失效时会继续尝试找目标；松开锁定键会清掉旧目标。
- **SB 没有手动锁定目标时，也能自动寻找墙后的可攻击敌人。** 搜索范围为附近 15 格。
- **调整幻影剑碰撞。** 修正同一步碰到实体和方块时的处理顺序；突进、暴风和螺旋剑阵进入方块后会停止，按旧版规则处理方块碰撞。
- **减少战斗、背包检查和掉落物处理的额外开销。** 评分规则不变。

客户端和服务端都需要更新。只安装 `slashblade-legacy-compat-forge-1.20.1-0.3.0-dev.16.jar`，不要与其他游戏版本或加载器的包混用。`sources.jar` 和源码 ZIP 是给开发者的。

以上为 dev.15 → dev.16 的重点变更；本次也首次把当前 1.20.1 移植源码同步到本仓库的 `ports/1.20.1`。
