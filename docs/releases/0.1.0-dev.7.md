# SEAC拔刀剑附属 旧梦重铸 0.1.0-dev.7

This development prerelease brings selected SlashBlade 1.12.2-era combat behavior to SlashBlade: Resharpened `2.0.5-1.21.1` on Minecraft `1.21.1` / NeoForge `21.1.248`.

Highlights include legacy broken-blade damage and reach, charge timing, default combos and movement, SB summoned blades, drive and projectile interactions, hostile/Gaia targeting compatibility, and earned sheathing repair after 1,000 Proud Souls.

Install the same runtime JAR on client and server. Back up the world first, do not pair it with another add-on version, and use the exact dependency versions in the README.

This remains a prerelease: automated minimal and locked full-mod server contracts passed, but real-client feel, multiplayer latency, production-world behavior, and live deployment are not accepted. See `VALIDATION.md` for the full boundary.

The source repository includes the MIT license for SEAC's independent implementation, the original legacy SlashBlade usage terms and attribution, dependency provenance, reproducible release metadata, and SHA-256 checksums.

OpenAI Codex materially assisted analysis, implementation support, testing, documentation, public-source review, and release preparation under maintainer direction.
