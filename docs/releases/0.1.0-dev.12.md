# SEAC拔刀剑附属 旧梦重铸 0.1.0-dev.12

开发预发布；Minecraft 1.21.1 / NeoForge 21.1.248 / Java 21 / SlashBlade: Resharpened 2.0.5-1.21.1。

## 更新

修复第一人称静止持刀和转动视角时的刀鞘位移：在相机空间固定持刀位置，抵消全局 model-view 与原绝对 yaw/pitch 的重复作用。整体向屏幕左侧平移 0.20，保留原始高度、大小、成对模型和动作。正式实现仅新增客户端 LegacyFirstPersonMixin；既有战斗、评级、SE、飞刀、盖亚、落地和神钢抢夺 III 均未改变。

## 证据与限制

内部冻结 dev.12 已完成实际 GUI 第一人称专项验证。散华和神威刀各测 8 个视角，刀身/鞘组合矩阵最大分量差从 1.68033495 降至 1.62811223e-7，低于 2e-5 阈值，并有截图复核。第三人称站姿正常。视角通过 Entity.turn 入口平滑变化，不代表硬件鼠标自动化。公开版 Java 实现保持一致，公开名称和许可证封装使 JAR 哈希不同；不另声称公开 JAR 已做 GUI 重测。

最初两次 dev.11 综合客户端基线在落地状态和第三次右键状态断言失败，尚未进入视角阶段；原因尚未完全确定，失败现场与断言保留。本轮独立视角探针通过不代表这两项已解决，也不代表全部连段/落地客户端测试通过。

公开构建与最小服务端契约由 CI 重跑；其结果不替代上述客户端失败的排查。未覆盖整包、多人延迟、光影/相机替换模组、左主手、其他 FOV、所有刀型或性能基准。未测量性能提升。

## 资产与安装

运行 JAR、sources JAR、源码 ZIP、manifest、SHA-256 清单共五项。仅运行 JAR 放入 mods；所有 client/server/persistence probe JAR 不发布到 Release，不安装到生产。依赖另行安装。源码保留独立探针任务以便复验。

客户端须更新才能获得显示修复；部署时检查双端版本一致。本发布不部署服务器或玩家包。dev.12 不改存档注册及战斗类，回退使用 dev.11 并保留世界/配置备份。独立代码 MIT；旧版衍生部分保留原作者条款与 AI 披露。
