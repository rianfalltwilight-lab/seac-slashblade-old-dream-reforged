# SEAC拔刀剑附属 旧梦重铸 0.1.0-dev.13

开发预发布；MC 1.21.1 / NeoForge 21.1.248 / Java 21 / SlashBlade: Resharpened 2.0.5-1.21.1。双端使用同版本。

## 修复

同一客户端退出世界再进入时，物品提示/属性查询可能在 SERVER 配置卸载期间发生，原先直接读取开关会抛出 Cannot get config value before config is loaded 并阻止加载。

统一配置读取入口：配置未加载时停用相关兼容处理；加载后实时读取。如果读取时发生卸载，只在确认已卸载时处理异常，其他异常继续抛出。21 个正式 Java 文件的 33 处读取使用此入口，不缓存跨世界开关、不创建临时默认配置。

保留 dev.12 的第一人称持刀与转视角修正，以及既有连段、剑气、下劈、评级、嘲讽、SE、飞刀和攻击筛选；神钢抢夺 III 不变。无注册或存档结构变化。

## 验证与限制

内部实际 GUI 最小客户端使用相同探针对照：dev.11 复现配置卸载后的同根异常，dev.13 同进程创建世界、退出、卸载、重新打开原世界通过。在真实 TagsUpdatedEvent 中查询泥土及标记断刀提示，重新加载后实时切换距离、伤害及 SB 开关均正常。两次 Java 正常退出并完成存档。

公开版 Java 与冻结源码一致，公开名称与许可证封装使二进制哈希不同；公开构建和最小服务端契约由 CI 重跑，不能代替公开 JAR 的 GUI 重测。

未重跑 252 模组整包、多人与服务端切换；最小客户端未安装触发原整包调用链的 TanukiDecor。第一人称图像复用 dev.12，旧连段/落地综合探针问题不因此视为解决。不宣称日志零错误或性能提升。
