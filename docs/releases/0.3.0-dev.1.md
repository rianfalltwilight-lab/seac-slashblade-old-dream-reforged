# 0.3.0-dev.1：每位玩家独立切换战斗系统

默认怀旧模式，按 **F8** 请求切换怀旧／重锋，也可在控制设置中改绑。每位玩家独立保存选择，服务器确认后切换动作、近战、蓄力、幻影剑、评分及旧版附魔效果。客户端和服务端都需要更新。

- 落地、松开攻击与特殊行动、完成收刀、结束剑技并关闭容器后切换；等待中再次按键取消。停止计时的已知投射物会安全收尾，过期攻击重新载入不会跨模式继续执行。
- 不重写刀的杀敌数、耀魂、精炼、耐久、附魔和保存的 SA。转交给不同模式玩家时，仅清理前一位的动作、蓄力状态。
- 大多数重锋或第三方 SA 无需转换。旧梦专属“急襲幻影剣-衰破”和 MaximumBet 在重锋模式临时使用原生次元斩并提示，切回后恢复原 SA。
- 累计包含此前整叠耀魂精炼、评分同步、二刀流和命中事件兼容改动。

冻结验证：服务端 **556 项**通过；集成服务端客户端完成两次切换、36 次连段、3 次单发幻影剑、跨维度、死亡重生，保留42张截图并抽查关键画面。源码独立重建主JAR及sources JAR均一致。

两个真实客户端互看、完整整包、高延迟、长期负载尚未验收。此前整包重复幻影剑反馈仍未复现，不宣称修复。未知附属持久剑技可能推迟切换。

Minecraft 1.21.1 / NeoForge / Java 21，必需 SlashBlade:Resharped。构建及本轮验证 NeoForge 21.1.248、重锋2.0.5；声明范围 NeoForge [21.1,)、重锋 [0,) 不代表所有版本均测试。
